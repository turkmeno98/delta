# Поля — журнал работ

Простое приложение для карты хозяйства и оперативного учёта работ по полям.

## Возможности

- Импорт полигонов полей из KML. Если в одной метке несколько полигонов, каждый добавляется отдельным полем.
- Название поля, площадь и связь с исходной подписью KML.
- Журнал запланированных, текущих и завершённых операций.
- Свои названия операций и отдельный выбор типа: сев, химическая обработка или другая работа.
- Для сева — культура/сорт и количество семян; для химработ — препарат, количество СЗР и единицы измерения.
- Поиск, фильтры по статусу, карта OpenStreetMap.
- Автоматическое сохранение в локальном хранилище браузера.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`, затем нажмите **Импортировать KML**. Для карты и шрифтов требуется интернет.

Данные полей и работ хранятся в браузере на этом устройстве и не отправляются на сервер. Перед очисткой данных браузера сохраните исходный KML отдельно. Повторный импорт того же KML сохраняет введённые названия и операции для совпадающих исходных подписей.
