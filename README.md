# Поля — общий журнал работ

Карта хозяйства с KML-полями, спутниковой подложкой, редактированием границ, журналом операций и общими данными для команды.

## Возможности

- Импорт полигонов из KML с подписями поверх каждого поля.
- Спутниковая и стандартная подложки карты.
- Редактирование контуров с автоматическим пересчётом площади.
- Названия полей и журнал запланированных, текущих и завершённых работ.
- Пользовательские названия и типы операций; для сева — культура, сорт и масса семян, для химработ — список СЗР с количеством и единицами.
- Вход по электронной почте, синхронизация между устройствами и приглашение коллеги по ссылке.
- Роли участника: агроном, оператор и наблюдатель.

## Подключение Supabase

Приложение использует существующие таблицы `farms` и `farm_members` для учётных записей хозяйств. Новые данные карты хранятся отдельно в `field_ops_fields`, `field_ops_settings` и `field_ops_invites`; таблицы старой агроплатформы не удаляются.

Перед первым входом выполните SQL из `supabase/migrations/20261025_field_operations_shared.sql` в SQL Editor проекта Supabase. Файл `supabase-config.js` содержит только URL и публичный publishable key; секретный `service_role` ключ браузеру не требуется.

В настройках Supabase Auth добавьте `https://turkmeno98.github.io/delta/` в список разрешённых Redirect URLs, чтобы подтверждение регистрации возвращало пользователя в приложение.

Если в Supabase включено подтверждение почты, участники должны сначала подтвердить адрес по письму. После входа владелец создаёт хозяйство (или выбирает уже доступное), импортирует KML и через кнопку с иконкой участников создаёт ссылку-приглашение. Ссылка действует семь дней.

## Локальный запуск

Нужен статический сервер, так как страница подключает Supabase и внешние карты:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.
